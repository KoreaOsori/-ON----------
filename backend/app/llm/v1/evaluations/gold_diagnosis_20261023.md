셉트린정의 설파메톡사졸·트리메토프림 행은 실제 존재한다. 두 행의 dur_ingr_code가 NULL이며 drug_ingredient에서 동일 이름의 유일 코드를 찾는 보완 조회도 실패한다. 새 dur_ingredient_rule에서 같은 성분명을 직접 조회한 결과 역시 후보가 없었다. 이를 성분 자체가 없다거나 모든 DUR 원본에 규칙이 없다는 뜻으로 확대할 수 없다.

코푸시럽과 코데농정에는 디히드로코데인(D000092), 클로르페니라민(D000893)이 공통이고 dl-메틸에페드린염산염도 동일 ingr_key로 존재한다. 마지막 성분은 코드 미연결이지만 동일 이름 키 기준 중복을 확인할 수 있다. 따라서 중복은 3개이며 코드로 연결된 두 성분에서 서로 다른 코드 조합은 1개다. 그 범위의 성분 금기 규칙 및 세 제품의 3개 제품쌍 금기 행은 이번 조회에서 미발견이었다. 셉트린정이 포함된 두 쌍은 성분 코드 비교 불가다.

성분 용량주의의 클로르페니라민 24밀리그램은 정제 제형 규칙이다. 이를 코푸시럽 자체의 상한이나 개인 권장량으로 표현하면 안 된다. 개선 답변은 제형 원문과 함께 제품 적용 여부 미확인인 성분 참고 자료로만 표시한다.

Gold snapshot은 2026-10-23이고 active vector snapshot은 2026-10-19(status=complete)였다. 현재 Repository가 버전 불일치를 감지해 벡터 검색을 중단하고 Gold로 조회하는 것은 의도된 동작이다. 최신 Gold와 일치하는 벡터 적재·공개가 필요하며 이번 v1 코드 변경으로 오래된 벡터를 강제 사용하지 않는다.

개선: 의약품만 있는 병용 전용 요청의 핵심 답변을 Python 사실 블록으로 고정하고 LLM은 모든 블록의 순서만 제안하도록 제한했다. 잘못된 모델 JSON/추가 문장/블록 누락은 기본 사실 순서로 대체한다. 임의 분류·한 약만 복용하라는 새 조언을 모델 출력에서 삽입할 수 없다. 원문 근거와 예외는 그대로 보존한다. 혼합 의도·건기식 답변은 기존 경로를 유지한다.
