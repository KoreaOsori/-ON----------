## 중요한 결함

1. **약물 분류의 잘못된 일반화**: 01/02에서는 세 제품을 같은 감기·알레르기 계열처럼 설명하지만 05에서는 셉트린정을 항생제로 구분한다. 외부 대조 자료인 [약학정보원 셉트린정(식약처 자료)](https://www.health.kr/drug/A11A0500A0065)에서도 설파메톡사졸/트리메토프림 성분의 항균제로 확인된다. 병용 질문에서 제품 근거를 넘어 일반화하는 문제가 있다.
2. **부분 비교 의미가 여전히 흐림**: 01의 '셉트린정의 성분을 비교용 자료에서 찾지 못해 금기 여부를 확인하지 못했어요'는 제품쌍 금기 조회와 성분 코드 비교를 구분하지 않는다. 응답만으로 실제 missing mapping 원인과 비교 조합 수를 확인할 수 없다. 수치/이유 설명을 프롬프트에 추가했지만 모델이 충실히 따르는지 확인되지 않았다.
3. **근거 범위를 넘어선 복용 변경 제안**: 03의 '한 가지만 복용하는 방향'은 제품쌍 판정 결과 안내를 넘어선다. 환자별 처방 맥락 없이 제품 선택을 제안하지 않도록 한 서비스 목표에 미달한다.
4. **용량 설명 범위 혼동**: 03은 정제 기준 성분 참고 상한을 두 제품 모두의 상한처럼 읽힐 수 있게 표현한다. 제품 제형과 성분 규칙 적용 여부가 다른데 이를 구분하지 않는다. 이 보고서는 해당 상한의 의학적 적정성을 인증하지 않는다.

중복 성분은 이번 01~03에서 세 이름으로 일관되게 출력됐다. 이전 출력의 두 이름과 달라졌지만 이름 키 비교와 코드 비교가 서로 다른 경로이므로 추가 이름이 곧 오류라고 단정할 수 없다. 실제 gold 및 서버 프롬프트를 보지 않아 데이터 일치 여부는 미검증이다.

## 검증 한계와 결론

API 연결과 응답 형식, 다제품 소개, 제외 제품 재언급은 이번 표본에서 개선됐다. 그러나 병용 답변 3건에서 중요한 표현 오류를 발견하여 전체 품질 합격으로 판단하지 않는다. 모델이 서로 다른 결과 유형을 합치거나 근거 밖 권고를 추가하는 현상을 우선 해결해야 한다.

이번 테스트는 DB 원문/서버 프롬프트/벡터 검색 이력/모델 실제 ID를 직접 확인하지 않았다. 공식 금기 양성 조합, 확정된 건기식 조합도 미포함이다. 소규모 표본이므로 안정성이나 의료적 정확도 비율을 산정할 수 없다. 성분 부족 원인을 고치려면 DB의 실제 매핑 행을, 출력 누락 원인을 고치려면 모델에 전달된 판정과 생성 결과를 구분해 점검해야 한다. 서비스 소스는 수정하지 않고 실행 스크립트와 결과/보고서만 v1/evaluations에 추가했다.
